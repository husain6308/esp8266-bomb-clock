# Contributing

Thank you for your interest in the ESP8266 Bomb Clock project.

## How to Contribute

You can contribute by:

- Reporting bugs
- Suggesting improvements
- Improving documentation
- Testing the firmware
- Improving hardware compatibility
- Sharing useful project ideas

## Bug Reports

When reporting a bug, please provide:

- ESP8266 board model
- Hardware configuration
- Firmware version
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Photos or screenshots when useful

## Feature Requests

For feature requests, please explain:

- What the feature should do
- Why it would be useful
- How it could improve the project

## Pull Requests

Before submitting a pull request:

1. Check the existing documentation.
2. Make sure your changes are related to the project.
3. Test your changes when possible.
4. Clearly describe what was changed.

## Firmware

The current repository provides the compiled firmware:

`esp8266-bomb-clock-v1.0.bin`

The original Arduino `.ino` source code is currently unavailable.
