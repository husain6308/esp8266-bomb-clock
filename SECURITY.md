# Security Policy

## Supported Versions

The following release is currently supported:

| Version | Supported |
|---|---|
| v1.0.0 | Yes |

## Reporting a Security Issue

If you discover a security issue related to this project, please report it privately to the project maintainer before publicly discussing or publishing the issue.

Please include:

- A description of the issue
- Steps to reproduce it
- Affected firmware version
- Relevant screenshots or logs, if available

## Responsible Disclosure

Please do not publicly publish sensitive information before the issue has been reviewed.

The project maintainer will review reported issues and determine whether a fix or update is required.

## Firmware Security

The current firmware is provided as a compiled `.bin` file.

The original Arduino `.ino` source code is currently unavailable.

Users should only flash firmware obtained from the official project repository or its official GitHub Releases.

## Disclaimer

This project is a hobby electronics project intended for entertainment, decoration and educational purposes.

The project should not be used to create, modify or control real explosive devices or weapons.
