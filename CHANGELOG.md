# Changelog

All notable changes to the ESP8266 Bomb Clock project are documented here.

---

## [v1.0.0] - Initial Release

### Added

- Initial stable ESP8266 Bomb Clock firmware
- NodeMCU Amica ESP8266 support
- DS1307 RTC timekeeping
- TM1637 4-digit clock display
- Passive buzzer alarm
- Physical alarm stop button
- Built-in ESP8266 Wi-Fi Access Point
- Built-in Web Server
- Web-based clock configuration
- Web-based alarm configuration
- Persistent settings stored in ESP8266 memory
- Android firmware flashing support
- Compiled firmware release
- Hardware wiring documentation
- Project photographs
- Web Server screenshots
- Android flashing documentation

### Firmware

- Firmware file: `esp8266-bomb-clock-v1.0.bin`
- Release: `v1.0.0`

### Flash Configuration

- Address: `0x0000`
- High-Speed Mode (Stub): ON
- Firmware Compress: ON
- Baudrate: `115200`

### Source Code

The original Arduino `.ino` source code is currently unavailable.

The repository therefore provides the compiled firmware together with hardware documentation and installation instructions.
